## Overview

Build Monitor provides a consolidated dashboard for CI pipelines across internal repositories.

## Key Features

- Real-time status for each monitored repository
- Failed pipeline highlighting with direct log links
- Trend view for success/failure rates over time

## Usage Guide

1. Open the dashboard and choose your team from filters.
2. Click any failed build to inspect logs and artifact metadata.
3. Use the trend chart to identify unstable repositories.

## Operational Notes

- Read-only access to GitHub and CI artifacts.
- Refresh interval is typically 5 minutes.
- Contact DevOps if your repository is missing from the list.
